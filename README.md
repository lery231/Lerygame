# Game Booster (khusus HP root)

Build: push ke GitHub (branch main) -> tab Actions -> unduh artifact `GameBooster-debug` (APK).
Pasang, buka, beri izin Superuser (Magisk / KernelSU / APatch).

Fitur: boost 1 ketuk, auto-boost per game, matikan thermal throttling, governor CPU/GPU performance,
kunci refresh rate, Game Mode, bersihkan RAM, overlay FPS+suhu, batas suhu aman + watchdog root.
Skrip sysfs ada di app/src/main/assets/*.sh dan bisa disesuaikan dengan HP kamu.
